# alexfranquelli.com

Rebuild of Alex Franquelli's writing portfolio and publication archive.

## Current status

- Static site, suitable for GitHub Pages
- Homepage selected work is randomly shuffled on each visit and can be reshuffled manually
- Writing archive has basic search and filters
- Archive-recovery research has started across Alex's former publications
- Existing alexfranquelli.com URLs will be preserved wherever practical before the final domain cutover

## Next stages

1. Complete the inventory of the current Squarespace site.
2. Recover missing bylines from live publisher archives, search indexes and the Wayback Machine.
3. Add article metadata and stable links/pages.
4. Refine typography, imagery and mobile behaviour.
5. Enable GitHub Pages on a preview URL.
6. Connect alexfranquelli.com only after the new site has been checked.
